# Alterações da versão 12

- Projeto preparado para hospedagem estática no GitHub Pages.
- Adicionado fluxo automático de publicação por GitHub Actions.
- Mantido `base: './'` no Vite para o sistema funcionar em repositórios com qualquer nome.
- Adicionado `.nojekyll` para evitar interferência do processamento Jekyll do GitHub Pages.
- Mantido React + TypeScript + Vite.
- Mantido armazenamento local dos relatórios.
- Mantida importação/exportação JSON.
- Mantida geração de PDF pelo próprio navegador.
- Mantidos comentários explicativos em português no código.
